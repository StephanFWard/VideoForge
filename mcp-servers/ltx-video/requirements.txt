# LTX-Video MCP server (video diffusion) - installed into `.venv-ltx`.

# The version pins matter. `ltx-video` was tested against transformers < 4.52,
# and the reference-media loader uses `av` (PyAV) for the CRF pre-compression
# step that keeps conditioning stills in the same codec space the VAE was
# trained on. Torch pulls a large wheel; on CPU-only boxes prefer the index at
# https://download.pytorch.org/whl/cpu to save several GB.
