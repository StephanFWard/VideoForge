VideoForge

Generate or edit videos with ComfyUI visuals, local foreground matting, Kokoro narration, and ffmpeg compositing.

Drop files here or click to choose
Images (png, jpg, webp) or videos (mp4, mov, webm) - they condition the render locally

Edit mode segments the moving foreground locally, composites generated theme imagery behind/in place of it, and replaces source audio with generated narration.

Leave foreground blank to keep the original subject. If both theme fields are blank, the main request is used as the background theme. Theme artwork requires ComfyUI; the uploaded video is segmented and composited locally. Foreground replacement is experimental: one generated subject image is fitted to the moving silhouette, not redrawn to match each pose.

LTX-Video settings

The preset list is shown by video-forge models. Frame counts must be N × 8 + 1 (9, 17, 25…) and sizes divisible by 32; VideoForge snaps them for you.
